# Shared selah.tools ADRs (mirrors)

Cross-app architecture decisions for the selah.tools family live in the **Cursor
Project Agent Store** at `/cursor/stores/self/docs/adrs/INDEX.md`. That store
copy is **canonical**.

Files in this folder are **mirrors** so GitHub PR reviewers can read Context and
Decision without the Agent Store. When a shared ADR changes, update the store
first, then refresh the mirror here.

Vault-only decisions stay in [`../../decisions/`](../../decisions/).
